Platform digital resmi milik **PT Fatih Jaya Film** yang dirancang untuk memperkuat branding perusahaan sebagai spesialis kaca film mobil dan gedung. Website ini mengedepankan kemudahan akses layanan panggilan (*home service*) dan profesionalisme visual.

---

## 💎 Brand Essence
- **Core Product:** Pemasangan Kaca Film (Mobil & Gedung).
- **USP:** Layanan Panggilan (On-site Installation).
- **Market:** Residential, Corporate, & Automotive Enthusiasts.

## 🛠️ Tech Stack & Architecture
Sistem dibangun dengan arsitektur yang fokus pada kecepatan pemuatan (Lighthouse Score) dan keamanan data.
* **Backend:** PHP 8.3 + Laravel 11.
* **Frontend:** Blade Templating + Tailwind CSS.
* **Database:** MySQL / PostgreSQL.
* **Integration:** WhatsApp Cloud API Shortcut.
